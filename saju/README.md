# 사주 오행 계산기 (saju/)

`ForcetellerStyleCalculator().calculate(생년월일, 시간 또는 None, "solar"|"lunar")` → 네 기둥 + 오행 비율 + 가장 많은 오행.

## 계산 순서
1. **시간 보정**: 당시 한국 표준시 → 서머타임 해제(1948~60, 1987~88) → UTC(1908~11, 1954~61은 UTC+8:30) → 시태양시(동경 127.5° 기준, KST−30분)
2. **네 기둥**: 년주는 입춘, 월주는 12절(VSOP87 축약 급수 + 장동·광행차·ΔT로 직접 계산, 천문연 발표와 ±1분), 일주는 율리우스일, 시주는 시태양시. 야자시(23시대)는 기본적으로 일주는 그날, 시간(時干)은 다음 날 일간 기준.
3. **오행 비율** (`elements.py`):
   - 궁성 보정: 천간 2, 월지 7, 일지 3, 년지·시지 2 (합 22) — 포스텔러 공개 역산값과 소수점까지 일치 (테스트 포함)
   - 조후 보정(월지): 未→火, 丑→水, 戌→4/7 水, 辰→4/7 木
   - 합충 보정: 천간합·육합(인접)·삼합·방합은 합화 오행으로 전환, 인접 충은 반감, 합에 참여한 글자는 충 면제.
     포스텔러의 내부 규칙은 비공개라 표준 명리 규칙으로 구현했고 `harmony=False`로 끌 수 있다.
4. **가장 많은 오행 하나**를 `dominant`로 선택 (동률이면 일간 오행 우선).

## 한계
- 앱의 생년월일 8자리 입력은 `YYYY-MM-DD`로 표시하고 API에서도 정규화 후 날짜를 검증합니다. 음력은 음력 달력 규칙으로 검사합니다.
- `birth_hour_branch="zi"|"chou"|...|"hai"`를 지정하면 선택한 12지시를 그대로 사용합니다. 시각 보정으로 다른 지시로 이동하지 않으며 자시의 일주는 입력한 생일을 기준으로 합니다. 연주·월주의 절기 판정에는 해당 구간의 대표 시각을 사용하므로 경계에서 정확한 출생 시각과 달라질 수 있습니다. 모름은 시주 없이 계산합니다. 기존 정확한 시각 입력 API도 유지하지만 지시와 동시에 입력할 수는 없습니다.
- 절기 시각은 천문연 발표와 1분 안에서 맞지만, 경계 ±1분 안의 출생은 월주가 달라질 수 있다 (발표 시각도 분 단위).
- 표준시·서머타임 이력은 공개 기록 기준으로 넣었으며 1961년 이전 출생은 확인을 권장.
- 출생지 경도를 받으면 `longitude=`로 지역별 시태양시 보정이 가능하다.
