### 추가 조사와 보류 사유

- 커먼즈에서 장소명의 File 검색으로 97곳 중 22곳에 결과가 있었다. 장소당 상위 5개까지 파일 메타데이터를 조사하고 우선 후보 12개 썸네일을 시각 검토했다. 경복궁 자경전 십장생굴뚝의 전경(궁능유적본부, 공공누리 1유형)과 부산대 박물관 앞 새벽뜰(부산대학교 홍보실, CC BY 4.0)을 후속 후보로 남겼다. 자갈치시장 실내 사진은 지점·권리가 일치해도 인물과 상품이 두드러져 보류했다. 지명만 같은 사진, 축제 회차 사진, 작품·세부 클로즈업도 승격하지 않았다. [국가유산청](https://www.heritage.go.kr/heri/cul/culSelectDetail.do?ccbaCpno=1121108100000&pageNo=1_1_1_1) · [부산대 교내 기록](https://pdf.channelpnu.pusan.ac.kr/1643/16431643.pdf)
- 서울관광아카이브의 검색 결과는 25곳 중 4곳에 있었다. 이촌한강공원의 가로수길은 지점·구도·제1유형을 확인했다. 파일 ID는 `ARP007wy1`, 제공자는 서울관광재단(Visit Seoul)이다. 원본 수령과 앱 표시를 검증한 뒤 승인할 후보로 남겼다. 국문 API에도 같은 공원이 있어 출처 두 곳을 순증 두 곳으로 계산하지 않았다. ‘어린이놀이터’, ‘휴식공간’, ‘영화 기생충 촬영지’는 특정 지점까지 일치시키지 못했다. [아카이브 개별 파일](https://archive.visitseoul.net/ko/contents/ARP007wy1) · [서울시 한강공원](https://hangang.seoul.go.kr/www/contents/660.do?mid=458)

## 노출과 우선순위 500곳

최근 30일 운영 통계의 스키마 v2, 운영 트래픽에서 `card_impression`과 `place_view`는 각각 0건이었다. 읽기 전용으로 집계했고 조회한 범위에 공개 이미지의 픽셀 로딩 성공 기록은 없다. **운영 노출 카드의 실제 사진 표시율은 미측정**이다.

11월 16일 촬영일로 로컬 공개 둘러보기의 도시별 첫 페이지 12장씩을 실제로 스크롤해 확인했다. 데스크톱과 모바일 웹에서 각각 서울 12/12, 부산 8/12, 강릉 6/12, 제주 4/12, 합계 **30/48(62.5%)**가 디코딩됐다. 두 화면은 같은 장소 표본이다. 전체 카탈로그 보유율의 분모는 활성 10,022곳이다.

첫 페이지의 미연결 18곳(제주 8, 강릉 6, 부산 4)을 먼저 배치했다. 나머지 482곳은 도시별 합계 125곳이 되도록 기존 카테고리를 순환하며, 같은 분류 안에서는 기존 도시 기준점에서 가까운 순으로 골랐다. ‘경포생태습지원’ 두 ID는 도형과 촬영 위치를 대조하기 전까지 한쪽 사진을 복제하지 않는다. 운영 조회가 쌓이면 같은 필터에서 장소별 실제 카드 노출·상세 조회 수를 재집계해 다음 검수 차례를 정한다. [500곳 우선순위 및 조달 경로](PHOTO_PRIORITY_500.md) · [지점 운영자 제출 양식 초안](PHOTO_OWNER_SUBMISSION_FORM.md)

첫 배치는 첫 페이지의 빈 카드, 두 번째는 같은 도시·유형에서 지점과 권리가 확인된 후보, 나머지는 지점 운영자 제출 또는 직접 촬영으로 넘긴다. 직접 촬영도 현장 촬영 허용과 제3자 권리를 확인한 뒤 같은 절차를 거친다. 새 사진은 기존 `place_id`와 파일 ID·URL·해시로 연결하고, 좋아요로 대표사진이 바뀔 때는 기존 사진별 분석 근거 연결 검사를 거친다. 이전 사진의 분석을 새 사진에 이식하지 않는다.
