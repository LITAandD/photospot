# 포토스팟 지점 대표사진 제출 양식 초안

카페·식당·베이커리와 공연·전시 시설의 운영자가 자신이 관리하는 지점을 소개할 때 사용하는 양식입니다. 접수 대상은 그 지점에서 이용자가 실제로 볼 수 있는 외관, 실내 또는 전망 사진 1장입니다. 체인은 지점마다 한 부를 작성합니다. 시설은 회차별 무대·전시 작품 대신 상설 로비·객석·외관을 우선합니다.

## 제출자가 작성하는 항목

| 항목 | 기입란 |
|---|---|
| 지점명·브랜드·정확한 지점 표기 | |
| 포토스팟 장소 링크 또는 장소 ID | |
| 도로명주소·건물·층, 지도 핀 또는 좌표 | |
| 장소 공식 페이지와 촬영 위치·방향 | |
| 사진 파일·작품명, 촬영일 또는 대략적인 연도 | |
| 촬영자와 저작권자, 화면에 표시할 이름 | |
| 게시할 출처 링크·라이선스 링크 또는 별도 이용허락 문서 | |
| 제출자 자격(촬영자·권리자·위임받은 운영자), 대리 시 권한 근거 | |
| 삭제·교체와 권리 확인에 사용할 업무용 이메일 1개(비공개) | |
| 개인 식별·미술품·간판·실내 촬영 관련 제3자 권리 및 확인 근거 | |
| 사용 가능 기간·추가 표기 조건, 기타 제한 | |

해당 지점에서 촬영했고 허락할 권한이 있는 파일만 제출합니다. 얼굴이 뚜렷한 손님·미성년자나 독립된 작품이 중심인 사진, 메뉴 클로즈업, 다른 지점 홍보사진, AI 생성 이미지는 대상에서 제외합니다. 권한 증빙은 필요한 부분만 제출하고 신분증·주민번호는 보내지 않습니다.

## 파일별 사용 범위

각 칸에 **허용 / 미허용** 중 하나를 직접 기입합니다. 공란은 미허용으로 처리합니다. 크롭이나 분석을 허용하지 않아도 그 선택을 그대로 기록합니다.

| 허용할 작업 | 선택 |
|---|---|
| 포토스팟 앱에 저작자·출처와 함께 공개 | |
| 포토스팟 웹에 저작자·출처와 함께 공개 | |
| 운영 서버·이미지 전송망에 저장·전송 | |
| 원래 비율을 유지한 리사이즈·썸네일 생성 | |
| 정사각형 크롭·일부 영역 표시 | |
| 사진 색상·명도·채도 분석 및 지점 근거 연결 | |
| 배경의 직선·곡선 등 형태 분석 및 지점 근거 연결 | |

분석 범위는 해당 사진에서 포토스팟 장소 특성을 추출하는 용도입니다. AI 모델 학습 허락은 이 양식에 포함하지 않습니다. 각 플랫폼은 자신의 공개·저장 허락과 기술 조건이 충족된 사진만 사용합니다. 원본 비율만 허용된 사진은 원본 비율을 보장하는 경로에서만 표시할 수 있습니다.

제출자 확인 이름 또는 업무상 서명 __________　권한 확인일 __________　양식 버전 __________

## 운영자 검수와 삭제·교체

1. 비공개로 수령한 파일에 접수번호·파일 해시를 부여하고 장소 ID, 지점 주소·좌표, 사진 속 외관·간판·구도를 대조합니다. 이전·폐점·동명이면 보류합니다.
2. 파일별 촬영자·권리자·제3자 권리·각 작업 허용값·기간·표시 문구를 기록합니다. 사진과 별도로 보관할 증빙의 접근자를 제한합니다. 특정 공연·전시 회차 사진은 상설 시설 대표 후보에서 제외합니다.
3. 원본과 앱 썸네일·상세를 사본에서 확인합니다. 기존 대표사진, 중복 해시·URL, 권리 제한, 저작자 표기를 점검한 뒤 승인된 사진만 공개 대상으로 넘깁니다. 분석에는 해당 파일의 식별값과 분석 허락을 함께 전달합니다.
4. 권리자는 접수번호 또는 장소 링크와 공개된 크레딧으로 비공개 처리·삭제·교체를 요청할 수 있습니다. 운영자가 확인 후 원본·캐시·썸네일·해당 사진 분석의 철회 처리를 기록하고 결과를 회신합니다. 새 파일은 신규 접수로 다시 검수합니다.
5. 접수 개시 전에 운영 주체와 실제 문의처, 증빙·업무 이메일·백업의 보존/삭제 기한, 철회 처리 기한, 이용허락 문구를 확정하고 양식 첫 화면에 고지합니다. 현재 문서는 초안이며 수신 채널을 열거나 운영자에게 발송하지 않았습니다.

## 향후 요청 문안

안녕하세요. 포토스팟은 방문자가 촬영하기 좋은 장소를 소개하는 서비스입니다. **[지점명·주소]**의 실제 외관이나 내부를 보여주는 사진 한 장을 제공하실 의사가 있으시면 **[확정된 접수처]**를 이용해 주세요. 촬영자와 출처를 표시하고, 앱·웹 공개, 보관, 썸네일 편집, 사진 특성 분석에 허용하신 범위만 사용합니다. 접수 전에는 **[권리·개인정보 안내]**에서 보관 기간과 삭제·교체 절차를 확인하실 수 있습니다.
