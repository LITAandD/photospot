## 사본에서 재현

저장소 루트에서 실행한다. 스크립트는 `artifacts/` 아래 별도 DB만 받는다. ID와 지점명·주소·지도 원문·좌표가 다르거나 필요한 허락이 빠지면 트랜잭션 전체를 되돌린다. 등록된 장소나 이미 쓰인 파일을 건너뛰고, 같은 명단을 다시 적용하면 같은 9행을 확인한다. 배포용 DB, 추천 로직, 운영 서버에서 실행하는 작업은 PR에 포함되어 있지 않다.

```sh
python -c "from pathlib import Path; from shutil import copyfile; p=Path('artifacts/round2.sqlite3'); p.parent.mkdir(exist_ok=True); assert not p.exists(); copyfile('catalog/places.sqlite3', p)"
python -m scripts.stage_round2_photos artifacts/round2.sqlite3
python -m scripts.stage_round2_photos artifacts/round2.sqlite3
python -m pytest -q tests/test_round2_photo_stage.py
```

웹 검증용으로 기존 앱을 export하고 필요한 Python E2E 의존성과 Chrome을 준비한다. 아래 첫 두 명령은 각각 별도 터미널에 실행한다. 서버는 전달받은 DB를 한 번 더 임시 복사하고 127.0.0.1에서 구동한다. 별도로 export한 동일 프런트엔드는 `--dist 경로`로 지정할 수 있다.

```sh
npm --prefix app run export
python app/e2e/round2_photos_smoke.py --serve 8796 --catalog catalog/places.sqlite3
python app/e2e/round2_photos_smoke.py --serve 8797 --catalog artifacts/round2.sqlite3
python app/e2e/round2_photos_smoke.py
```
