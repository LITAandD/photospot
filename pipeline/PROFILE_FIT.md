# 카탈로그 정합도 v2

2026-10-07 요청 기준. 공개 웹과 인증 API의 `catalog` 추천에 함께 적용한다.
이는 사용자가 선택한 취향 규칙이며, 체형·MBTI에 따른 과학적 적합성이나 실시간 혼잡 예측이 아니다.
PostGIS 장면 엔진의 기존 SQL/샘플 규칙은 별도 버전이다.

## 점수

| 입력 | 관찰/근거 | 가중치 | 일치 기준 |
| --- | --- | ---: | --- |
| 웜/쿨 | 대표 사진의 색조 통계 | 28 | 난색→봄·가을 웜, 한색→여름·겨울 쿨 |
| 세부 톤 | 사진 명도·채도 | 6 + 6 | 기존 세부 톤 규칙 유지 |
| 체형 | 검토한 대표 사진의 우세한 배경 형태 | 30 | 곡선→웨이브, 직선→내추럴, 큰 형체→스트레이트 |
| 키 | 사진 검토/지도 실내외 태그/시설 유형 | 10 | 170cm 초과→야외, 미만→실내, 정확히 170cm→중립 |
| MBTI E/I | 최근 완료된 3개월 장소별 입장객 합계의 전역 순위 | 4 | E는 상위, I는 하위 방문량 선호 |
| MBTI S/N·T/F | 검토된 공간 성격·사진 분위기 | 4 + 4 | 기존 규칙 유지; 미관찰 항목 제외 |

전체 가중치 92 중 입력과 근거가 있는 항목만 분모에 포함한다.
새로운 색조·형태·실내외 기준은 일치 1, 불일치 0, 중립 0.5를 가중치에 곱한다.
중성 색조, 실내외 혼합 공간, 키 170cm는 중립이다. 명도·채도의 기존 감점은 유지한다.
조명 16+색온도 12를 색조 28로, 형태 15+질감 15를 형태 30으로 통합해 중복 가산을 피한다.
색조는 사진의 촬영·보정 결과이며 현장 광원의 켈빈 온도를 측정한 값이 아니다.

## 추천 정렬 (2026-10-08)

검색 조건에 맞는 전체 후보를 평가한 뒤, 실제 평가된 항목 수 내림차순 → 정합도 점수
내림차순으로 정렬하고 결과 개수 제한을 적용한다. 항목 수는 `status=scored` 기준이며
0점·감점 항목도 센다. 미평가·입력 누락 항목은 제외한다. 가중치 합계나 사진 장수가 아니다.
예를 들어 5항목·70점 장소가 3항목·100점 장소보다 먼저 나오고, 5항목끼리는 높은 점수가 먼저다.

오행 추천도 우선 오행에 맞는 장소를 추린 뒤 같은 두 기준으로 정렬한다.
두 기준이 모두 같으면 오행 종합 점수(오행 추천일 때), 사진 유무, 보조 프로필 선호,
공개 인기 지표, 가까운 거리, 장소 ID 순으로 동점을 해소한다.
기본 목록과 오행 목록에 평가 항목 수를 표시하며, 목록과 상세는 같은 정합도를 사용한다.

## 사진 근거와 갱신

- `data/catalog_photo_reviews.json`: 2026-10-07 실제 대표 사진 517장 검토. 493장에 형태를 기록한다.
  직선은 기둥·창틀·난간 등 반복되는 곧은 윤곽, 곡선은 아치·원형 지붕·곡선 길 등의 우세한 윤곽,
  큰 형체는 독립된 큰 건물 덩어리·석재·바위 등 부피감 있는 형체를 기준으로 구분한다.
  작게 보이는 로고 원형/글자는 우세 형태의 근거로 사용하지 않는다.
- 검토는 정확한 장소 ID, 사진 URL, 원문 URL에 묶인다. 다른 사진으로 바뀌면 재검토가 필요하다.
  확실한 우세 형태가 없는 사진 24장은 형태를 제외하고, 그 중 공간을 판단할 수 없는
  인물·문서·물품 클로즈업 6장은 색조를 포함한 사진 정합도 근거에서 제외한다.
- 현재 추천은 대표 사진 한 장 기준이며 장소 전체·모든 시간대의 특성을 보장하지 않는다.
  사진의 외관과 시설의 실내 이용 여부는 다른 근거다. 카페·박물관·갤러리·공연장은
  시설 유형에 따른 실내 추정, 공원·수변·자연 명소는 야외 추정으로 표시한다.
  야외 좌석이 등록된 실내 시설은 혼합 공간, 불명확한 명소·유적은 미평가로 둔다.
- `python -m pip install -r requirements-analysis.txt` 후
  `python -m pipeline.catalog_visuals --limit 10000 --workers 2`로 색 분석/형태 검토 후보를 갱신한다.
  OpenCV 윤곽 분석은 검토 후보 생성용이다. 형태 오분류를 확인했으므로 **검토되지 않은
  자동 형태는 서비스 점수에 사용하지 않는다**. 검토 결과를 데이터 파일에 추가한다.
  공개 이미지 캐시는 `storage/analysis-photos`에만 저장하며 배포하지 않는다.
- 사진이 삭제되거나 연결이 달라지면 기존 근거를 무효화한다. 요청 처리 중에는 외부 사진을 내려받지 않는다.

OpenCV 참고: [직선 검출](https://docs.opencv.org/4.x/d9/db0/tutorial_hough_lines.html),
[윤곽 특징](https://docs.opencv.org/4.x/dd/d49/tutorial_py_contour_features.html).

## 공개 방문객 통계

조회일(KST) 기준 최근 **완료된 3개월**을 사용한다. 2026-10-07에는 2026-07~09이며,
촬영일을 미래로 선택해도 아직 발생하지 않은 방문객 수를 사용하지 않는다.
조회 반경·지역·유형 필터 전에 전체 활성 DB에서 동일 기간이 완전한 장소만 집계한다.

- 세 달 모두 월간 입장객 수가 있어야 합산한다. 공개된 실제 0은 유효하나 누락을 0으로 채우지 않는다.
- 장소별 `admissions`(월간 입장 횟수/입장객 수)만 받는다. 리뷰 수, 검색 수,
  시군구 유동인구, 누적 개관 방문객, 행사 방문객, 일부 일자 수치를 대체하지 않는다.
- 동점은 같은 순위와 평균 백분위를 부여한다. 백분위
  `p = (더 적은 장소 수 + (동점 수-1)/2) / (집계 장소 수-1)`.
  E 점수는 `4p`, I 점수는 `4(1-p)`. 집계가 1곳 이하면 순위 평가를 보류한다.
- 장소별 전체 기간 방문객 수, 출처, 기간, DB 전체/집계 장소 수를 화면에 표시한다.
  일부만 집계됐을 때 이를 전체 DB 모든 장소의 확정 순위라고 표현하지 않는다.
- 월이 바뀌면 기간 밖 자료는 자동으로 점수에서 제외한다. 수집 자체는 명시적 배치 작업이다.

### 2026-10-07 공개 자료 확인 결과

[관광지식정보시스템 주요관광지점 통계](https://know.tour.go.kr/stat/visitStatDis/table.do)는
2026-06까지 공개(2026-08-18 갱신)되어 있다. 7~9월 완전한 장소별 비교 자료로 사용할 수 없다.
해당 통계는 등록된 지점만 대상으로 하며 분기 종료 후 약 45일 뒤 잠정치를 공표한다.
[통계 소개](https://know.tour.go.kr/stat/visitStatDis/introduce.do).

[한국관광 데이터랩 지역별 현황](https://datalab.visitkorea.or.kr/datalab/portal/loc/getAreaDataForm.do?SGG_CD=51810)은
지역 방문자와 목적지 검색 순위를 구분한다. 지역 방문자·내비게이션 검색량을 개별 장소 입장객 수로 넣지 않는다.
카페를 포함한 전체 DB 10,453곳의 7~9월 입장객 수를 확인하지 못했으므로 초기 스냅샷의 해당 집계는 0곳이다.
이는 **방문객 0명**이 아니라 **미집계**다. 사용자가 공개 자료만 사용하고 누락은 미집계로 두도록 선택했다.

### 가져오기

공개 원문에서 동일한 개별 장소인지 위치·시설 범위까지 확인한 뒤 JSON 배열로 기록한다.
필수 키: `place_id`, `month`(`YYYY-MM`), `visitors`(0 이상의 정수), `source_url`(공개 HTTPS 원문),
`source_label`, `published_at`(`YYYY-MM-DD`), `count_basis`(`admissions`).
같은 달 중복 입력, 미래·미완료 월, 기간 전에 공표된 수치, 소수/누락 방문객, 잘못된 장소 ID는 거절한다.
숫자를 추정하거나 서로 다른 지점/기간의 숫자를 결합하지 않는다.

```powershell
.venv/Scripts/python.exe -m pipeline.catalog_visitors reviewed-monthly-visitors.json
.venv/Scripts/python.exe -m scripts.export_catalog
```

전체 입력을 검증한 후 하나의 트랜잭션으로 저장한다. 원문 수정 시 같은 장소/월을 교체한다.
배포 스냅샷에는 공개 `catalog_visitors` 테이블만 추가한다. 프로필과 개인 방문 이력은 수집하지 않는다.
